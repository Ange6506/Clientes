Proyecto Clientes
    Tecnologías usadas
    - React
    - TypeScript
    - Vite
Antes de ejecutar el proyecto debes tener instalado:
- Node.js
- Visual Studio Code o Visual Studio 2022

Crear el frontend con:
en la terminal pon: npm create vite@latest frontend -- --template react-ts
Entrar a la carpeta: cd frontend
Instalar dependencias: npm i o npm install
Correr el frontend: 
npm run dev
